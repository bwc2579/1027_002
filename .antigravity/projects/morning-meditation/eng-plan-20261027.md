## 3. Error & Rescue Map (Zero Silent Failures)

| Failure Mode | Root Cause | Rescue & Fallback Strategy | User-Facing Indication |
|---|---|---|---|
| **YouTube API Block / Offline** | Network disconnect or ad-blocker blocking YouTube IFrame | Seamlessly fallback to Web Audio API ambient sound generator (Rain/Binaural synth) | Subtle notification: "오프라인 모드: 내장 힐링 사운드로 재생합니다" |
| **Gemini API Failure / No Key** | Missing API key, quota limit, network error | Fallback to built-in high-vibe curated affirmation library (50+ curated Korean quotes) | AI 뱃지 대신 '데일리 큐레이션' 라벨로 끊김 없는 경험 제공 |
| **TTS Unavailable** | Browser doesn't support Web Speech API | Gracefully hide the audio play button, text remains fully readable | 조용히 버튼 숨김 (무에러 정책) |
| **Storage Quota Exceeded** | LocalStorage filled with massive data | Automatically compact or migrate to IndexedDB; alert user to export backup | "저장 공간 최적화 완료 (백업 권장)" 안내 모달 |
| **Accidental Tab Close** | User closes browser while writing journal | Autosave input to `localStorage['draft_today']` on every keystroke | 재접속 시 작성 중이던 글 100% 자동 복구 |

## 4. Test Matrix ("Boil the Lake" 100% Coverage)

- **Unit Tests:**
  - Storage CRUD: 날짜별(YYYY-MM-DD) 일기 저장, 수정, 삭제, 날짜 검색 정확도 검증
  - Streak Calculator: 어제 작성 후 오늘 작성 시 연속일 증가, 하루 건너뛸 시 리셋 로직 검증
  - Web Audio Mixer: 노이즈/오실레이터 노드 생성, 볼륨 페이더 조절, 음소거 동작 검증
  - AI Service: API 키 유무에 따른 실시간 생성 vs 로컬 큐레이션 풀백 스위칭 검증
- **E2E / Interaction Tests:**
  - 루틴 완주 플로우: 음악 재생 → 확언 생성 → 일기 작성 → 저장 → 캘린더 반영 검증
  - 날짜 검색: 특정 날짜 클릭 시 해당 일기 및 감정 태그 정확히 로드되는지 검증
  - 백업/복원: JSON Export 다운로드 및 Import 복원 무결성 검증
