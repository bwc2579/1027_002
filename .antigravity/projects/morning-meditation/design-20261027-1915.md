## 1. Problem Framing & Demand Reality

### 1.1 The Real Problem
현대 2030 직장인들은 출근 전 아침마다 번아웃, 업무 압박, 불안감에 짓눌려 하루를 무기력하게 시작합니다. 이를 극복하고자 명상이나 미라클 모닝 루틴을 시도하지만, 기존 솔루션에는 치명적인 결함이 있습니다:
- **도파민 유혹과 탈선:** 유튜브나 인스타그램에서 '명상 음악'이나 '동기부여 글'을 찾으려다가 알고리즘 쇼츠나 피드 알림에 빠져 오히려 시간을 낭비하고 멘탈이 흐트러짐.
- **분절된 도구 (Duct-taped Workflow):** 유튜브(음악) + SNS(명언) + 카카오톡/메모장(기록)으로 앱을 3개씩 오가다 보니 매일 아침 에너지 소모가 심해 3일을 넘기지 못하고 포기함.

### 1.2 Target Persona: The Desperate User
- **대상:** 출근길 지하철에서 가슴이 답답하고, 하루를 온전히 내 의지로 시작하지 못해 무력감을 느끼는 2030 직장인.
- **필요:** 다른 유혹 없이 단 5분 동안 [음악 감상 → AI 맞춤 확언 낭독 → 오늘의 다짐 기록]을 한 호흡(Single Flow)에 끝내는 멘탈 리셋 도구.

---

## 2. Core Value Proposition & Principles

1. **Zero-Distraction Single Flow (탈선 없는 5분 루틴):**
   앱을 켜면 탐색할 필요 없이 오늘의 명상 음악과 글이 즉시 준비되어 있으며, 완료 후 바로 오늘의 마음가짐을 기록할 수 있습니다.
2. **AI-Powered Personalized Priming (AI 맞춤형 확언/명상 스크립트):**
   단순한 명언 복사/붙여넣기가 아니라, 사용자의 어제 감정이나 아침 상태에 공감하는 따뜻하고 활기찬 맞춤형 모닝 스크립트를 제공합니다.
3. **Local-First & Complete Privacy (로컬 우선 프라이버시):**
   개인적인 내면의 기록이 외부 서버로 유출되지 않도록 브라우저 로컬 스토리지/IndexedDB에 안전하게 영구 저장되며, 날짜별 검색과 타임라인 조회가 즉시 작동합니다.

## 3. Product Specification & Requirements

### 3.1 Feature 1: Morning Meditation Audio (YouTube Embed)
- 매일 아침 차분한 마음을 유도하는 엄선된 힐링/명상 유튜브 음악 추천 (Lofi, Nature Ambient, Binaural Beats, Singing Bowl 등 테마별 큐레이션 프리셋).
- YouTube IFrame API 연동: 군더더기 없는 미니멀 플레이어로 영상 속 광고 유혹이나 관련 동영상 링크로의 이탈 최소화.
- 타이머 기능 (3분 / 5분 / 10분) 지원.

### 3.2 Feature 2: Daily Priming & AI-Generated Morning Script
- **오늘의 활력 메시지:** 그날을 활기차고 새로운 마음가짐으로 맞이할 수 있는 영감 가득한 글감.
- **AI 맞춤 명상 스크립트:** Gemini API를 통해 오늘 하루를 시작하는 따뜻한 확언(Affirmation) 및 1분 호흡/마인드풀니스 가이드 생성 기능.

### 3.3 Feature 3: Mindset Reflection Journal (마음가짐 기록)
- 명상과 글을 읽은 직후, 마음에 떠오른 생각과 오늘 하루의 다짐을 적는 퀵 저널 에디터.
- 템플릿 프롬프트 제공 (예: "오늘 내가 가장 감사한 한 가지", "오늘 꼭 지키고 싶은 마음가짐").
- 기분/감정 태그 (평온함, 설렘, 비장함, 불안 해소 등) 원클릭 선택.

### 3.4 Feature 4: Persistent Archive & Date Search (기록 저장 및 날짜별 검색)
- 모든 일기와 확언 내역을 영구 저장 (LocalStorage / IndexedDB).
- 캘린더 뷰 및 날짜별 검색: 과거 특정 날짜를 클릭하면 그날 들었던 음악, 읽었던 글, 기록한 마음가짐을 즉시 열람.
- 데이터 내보내기/가져오기 (JSON 백업) 지원.

## 4. System Architecture

```
[ Frontend: Modern Responsive Web App ]
  │
  ├── UI Components (Zen / Calm Aesthetics)
  │     ├── Header & Date / Streak Indicator
  │     ├── YouTube Ambient Player (Embedded IFrame)
  │     ├── Morning Reading & AI Affirmation Card
  │     ├── Quick Journal Editor with Sentiment Tags
  │     └── Calendar Timeline & Date Search Drawer
  │
  ├── State & Storage Layer (Local-First)
  │     ├── LocalStorage / IndexedDB (Complete Privacy)
  │     └── History & Search Engine (by Date, Keyword, Mood)
  │
  └── External Integrations
        ├── YouTube IFrame Player API
        └── Gemini API (Affirmation & Script Generation)
```

## 5. UI/UX Design Dimensions (Calm & Intentional)

- **색상 팔레트:** 차분한 새벽빛 웜 그레이(#F8F9FA, #1A1D20), 소프트 엠버 골드(#D97706), 딥 슬레이트 네이비(#0F172A).
- **폰트 & 타이포그래피:** 가독성이 높고 감성적인 프리텐다드(Pretendard) / Noto Serif 기반.
- **인터랙션:** 잔잔한 페이드 인 애니메이션, 주의를 분산시키지 않는 미니멀 버튼 배치.

## 6. Implementation & Test Strategy ("Boil the Lake")

- **Zero Shortcuts:** 브라우저 새로고침 시에도 작성 중인 일기 자동 임시저장(Autosave), 날짜별 정확한 인덱싱, 예외 처리(오프라인, API 장애 시 기본 큐레이션 글 풀백 제공).
- **테스트 케이스:**
  1. 유튜브 임베드 로딩 및 컨트롤 동작 검증
  2. 일기 작성 후 저장 및 날짜별 검색/필터링 정확도 100% 검증
  3. 날짜 변경 시 이전 기록 정상 표시 및 오늘 기록 작성 방어 로직 검증
  4. 데이터 백업(Export/Import) 무결성 테스트
